# little-birthday-snail

A snail carries a lit birthday cake up the hill at dusk, and the candle is the only warm light left in the picture. The program draws the whole scene in plain Python, pixel by pixel.

A 1024x1024 dusk scene drawn from scratch: a snail with a two tier birthday cake on its shell, a lit candle, confetti, fireflies and the silver trail it came in on. No network, no packages, no randomness: two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
